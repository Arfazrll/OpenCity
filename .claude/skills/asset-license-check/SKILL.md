# asset-license-check

1. List all files under `assets/` (exclude `LICENSES.md` itself).
2. For each file, find its row in `assets/LICENSES.md` with: file path, source URL, author, license,
   date downloaded, modifications made.
3. **Allowed licenses**: `CC0-1.0`, `CC-BY-3.0`, `CC-BY-4.0`, `OFL-1.1`, `MIT`, `Apache-2.0`.
4. Report missing or disallowed entries and **block the commit until fixed**.

## Output format

```text
assets/textures/concrete_01_albedo.png   OK      CC0-1.0      ambientCG
assets/fonts/Inter-Regular.ttf           OK      OFL-1.1      rsms
assets/audio/ambient_city.ogg            MISSING  -           -> BLOCK
assets/models/tree_oak.glb               DENIED   CC-BY-NC    -> BLOCK (NC not allowed)

4 files checked, 2 problems -> commit blocked
```

## Hard-rule reminders (blueprint 3.2, items 1–4)

These are non-negotiable. If any is in doubt, **stop and ask the owner** — do not guess:

- Nothing ripped, extracted, traced or lightly modified from any game or commercial product.
- Nothing from EA / Maxis / SimCity, ever.
- No "free for personal use", NC or ND licenses — the repo is public and MIT, so every asset is
  redistributed.
- No real brand logos; no exact replicas of distinctive copyrighted landmark designs.

## Procedural output

Assets generated by our own code are allowed and still need a row, with source
`procedural (crates/procgen)` and license `MIT` (same as the code that made them).

## AI-generated assets

Only if the tool's terms grant output rights compatible with public redistribution. The row must
record the tool, its version and the prompt used. If the terms are unclear → **DENIED**, ask the
owner.
